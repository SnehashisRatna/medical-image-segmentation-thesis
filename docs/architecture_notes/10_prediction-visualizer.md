# PredictionVisualizer

The **PredictionVisualizer** is a visualization component responsible for the qualitative analysis of segmentation results generated by a **single medical image segmentation model**.

Unlike the **ComparisonVisualizer**, which evaluates predictions from multiple architectures simultaneously, the **PredictionVisualizer** focuses on detailed inspection of one prediction. It enables researchers to visualize the original medical image, the predicted segmentation mask, the corresponding ground truth, overlay visualizations, and pixel-wise difference maps.

The module produces publication-quality visualizations that support qualitative evaluation throughout the research lifecycle.

# Overview

The **PredictionVisualizer** provides a standardized interface for visualizing the prediction generated by a single segmentation model.

Rather than comparing multiple architectures simultaneously, this module concentrates on understanding the behavior of one model through detailed qualitative inspection.

It enables researchers to:

- Inspect predicted segmentation masks
- Compare predictions with ground truth
- Visualize anatomical boundaries
- Generate overlay visualizations
- Identify segmentation errors
- Produce publication-quality figures

The visualizer is completely independent of the underlying segmentation architecture and therefore supports CNN-based, Transformer-based, and future hybrid segmentation models.

---

# Purpose

Medical image segmentation research requires considerably more than numerical evaluation metrics such as the **Dice Similarity Coefficient (DSC)** or **Intersection over Union (IoU)**.

Researchers must visually inspect segmentation outputs to:

- Understand prediction quality
- Identify failure cases
- Evaluate anatomical boundary alignment
- Detect over-segmentation and under-segmentation
- Verify prediction consistency

The **PredictionVisualizer** addresses these requirements by providing reusable visualization utilities dedicated to the qualitative assessment of predictions generated by a single segmentation model.

The module supports visualization during:

- Model development
- Training validation
- Benchmarking
- Error analysis
- Thesis preparation
- Research publication

---

# Design Philosophy

The **PredictionVisualizer** follows the **Single Responsibility Principle (SRP)**.

Its sole responsibility is generating qualitative visualizations for **one segmentation prediction**.

The class intentionally does **not**:

- Perform neural network inference
- Compute segmentation metrics
- Compare multiple segmentation models
- Load datasets
- Perform preprocessing
- Modify prediction results

Separating visualization from inference and evaluation promotes:

- Modular architecture
- Code reuse
- Easier maintenance
- Improved testability

# Responsibilities

The **PredictionVisualizer** is responsible for:

- Rendering the original medical image
- Displaying the predicted segmentation mask
- Displaying the corresponding ground truth segmentation
- Creating prediction overlay visualizations
- Generating pixel-wise difference maps
- Exporting publication-quality figures
- Validating visualization inputs prior to rendering

---

# Non-Responsibilities

To comply with the **Single Responsibility Principle (SRP)**, the **PredictionVisualizer** does **not** perform:

- Reading DICOM images
- Reading segmentation masks
- Dataset management
- Image preprocessing
- Image normalization
- Neural network inference
- Model training
- Quantitative metric computation
- Statistical analysis
- Multi-model comparison

These responsibilities belong to other dedicated components within the framework.

# Public API

## `render()`

Renders the original medical image together with its predicted segmentation mask.

### Purpose

Provides the default visualization interface for prediction inspection.

Internally, this method delegates rendering to `render_prediction()`.

---

## `render_prediction()`

Displays the original medical image together with its predicted segmentation mask.

### Output

```text
+----------------+----------------+
| Original Image | Prediction     |
+----------------+----------------+
```

This view enables rapid inspection of segmentation quality.

---

## `render_ground_truth()`

Displays the original medical image together with the corresponding ground truth segmentation.

### Output

```text
+----------------+----------------+
| Original Image | Ground Truth   |
+----------------+----------------+
```

This visualization provides the reference annotation used during qualitative analysis.

---

## `render_overlay()`

Overlays the predicted segmentation mask on the original medical image.

### Output

```text
+----------------+----------------------+
| Original Image | Prediction Overlay   |
+----------------+----------------------+
```

Overlay transparency is configurable through the `alpha` parameter.

This visualization is useful for evaluating:

- Anatomical alignment
- Boundary accuracy
- Segmentation coverage
- Missed anatomical regions

---

## `render_difference()`

Generates a pixel-wise difference map highlighting disagreement between the prediction and the ground truth segmentation.

### Output

```text
+----------------------+
|   Difference Map     |
+----------------------+
```

Difference maps provide rapid visual identification of:

- False positives
- False negatives
- Boundary inconsistencies
- Localization errors

---

## `save()`

Exports rendered figures to disk.

The method automatically:

- Creates missing directories
- Saves publication-quality figures
- Closes Matplotlib figures to prevent memory leaks

# Internal Helper Methods

The implementation is organized into reusable helper methods.

## Validation

### `_validate_inputs()`

Validates all visualization inputs before rendering.

---

### `_validate_masks()`

Ensures prediction masks and ground truth masks:

- Exist
- Share compatible dimensions
- Have valid data types

---

### `_validate_alpha()`

Validates overlay transparency.

Allowed range:

```text
0.0 ≤ alpha ≤ 1.0
```

---

### `_validate_dpi()`

Validates figure resolution before export.

---

### `_validate_figsize()`

Ensures requested figure dimensions are valid.

---

## Figure Construction

### `_create_figure()`

Creates Matplotlib figures using standardized layout, resolution, and formatting.

---

## Rendering Helpers

### `_display_image()`

Displays the original medical image.

---

### `_display_mask()`

Displays segmentation masks using the reusable **MaskVisualizer**.

---

### `_display_overlay()`

Displays image-mask overlays using the reusable **OverlayVisualizer**.

---

### `_display_difference()`

Generates pixel-wise difference visualizations between prediction and ground truth.

These helper methods eliminate duplicated rendering logic while maintaining visual consistency throughout the framework.

# Visualization Types

The **PredictionVisualizer** supports four primary visualization modes, each designed to assist qualitative evaluation of segmentation results throughout the research workflow.

---

## Prediction Visualization

Prediction visualization displays the original medical image alongside the predicted segmentation mask generated by a segmentation model.

```text
+----------------+----------------+
| Original Image | Prediction     |
+----------------+----------------+
```

This visualization enables researchers to perform rapid inspection of model outputs and verify whether the predicted anatomical structures correspond to the expected regions.

### Applications

- Model development
- Qualitative inspection
- Prediction verification
- Debugging segmentation models
- Preliminary experiment analysis

---

## Ground Truth Visualization

Ground truth visualization displays the original medical image together with the corresponding expert-annotated segmentation mask.

```text
+----------------+----------------+
| Original Image | Ground Truth   |
+----------------+----------------+
```

This visualization serves as the reference standard against which model predictions are evaluated.

### Applications

- Annotation verification
- Dataset inspection
- Manual quality assessment
- Ground truth validation
- Dataset exploration

---

## Overlay Visualization

Overlay visualization superimposes the predicted segmentation mask on the original medical image.

```text
+----------------+----------------------+
| Original Image | Prediction Overlay   |
+----------------+----------------------+
```

The overlay transparency can be adjusted using the configurable **alpha** parameter, allowing researchers to inspect anatomical alignment while preserving visibility of the underlying medical image.

### Applications

- Anatomical localization
- Boundary inspection
- Segmentation coverage analysis
- Clinical interpretation
- Publication-quality visualization

---

## Difference Visualization

Difference visualization generates a pixel-wise comparison between the predicted segmentation and the ground truth annotation.

```text
+----------------------+
|   Difference Map     |
+----------------------+
```

Regions where the prediction differs from the reference annotation are highlighted, enabling rapid identification of segmentation errors.

### Applications

- False positive analysis
- False negative analysis
- Boundary error identification
- Localization error detection
- Failure case analysis

- Softmax probability heatmaps
- Multi-class segmentation visualization
- Interactive visualization
- Uncertainty visualization
- Volumetric (3D) visualization

Restricting the scope of the current implementation simplifies maintenance while preserving a modular foundation for future enhancements.
